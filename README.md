# Text to PDF Generator

A browser-based Text to PDF Generator built with HTML, CSS, JavaScript and Python Flask.

## Features

- Convert text into PDF
- Generate PDF directly from the browser
- Support for formatted documents
- Simple and responsive interface
- Mobile, tablet and desktop friendly
- Python Flask backend
- PDF generation through backend API
- Download generated PDF
- Designed for easy integration with other web tools
